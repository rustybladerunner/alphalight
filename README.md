# Alphalight

Browser flicker / warm-light stim tool (10Hz / 40Hz). Static HTML + CSS -- no backend.

**Live demo:** https://rustybladerunner.github.io/alphalight/

> **Photosensitivity warning:** This page can flash light at 10Hz and 40Hz. Do **not** use if you have epilepsy, migraine sensitivity to flicker, or other photosensitivity. Stop immediately if you feel unwell. Not a medical device.

## Features

- **Alpha Mode (10Hz)** -- 10Hz flicker
- **Gamma Mode (40Hz)** -- 40Hz flicker
- **Bright / warm slider** -- blend daylight-like white toward warmer tones

## Usage

1. Open the [live demo](https://rustybladerunner.github.io/alphalight/) or `index.html` locally.
2. Choose Alpha or Gamma mode.
3. Adjust the warmth slider as desired.

## Getting started

```bash
git clone https://github.com/rustybladerunner/alphalight.git
cd alphalight
# open index.html in a browser, or serve the folder with any static server
```
